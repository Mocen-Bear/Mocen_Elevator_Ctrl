# 烧录程序包 · 版本信息

- **包名：`烧录程序`**（独立包，**不属于**已有的任何包）
- **包版本：v8** ／ **固件版本：v8**（包号和固件号一起涨，沿用 v6 起的习惯）
- **上一版：v7**（磁盘上已删除，只留这一版）
- **打包日期：2026-10-18**
- 场景：一台电梯，井道 **B / 1F / 2F / 3F**，**呼梯装置装在 1F / 2F**（广播名 `ELEV-1F` / `ELEV-2F`）

## 这是什么

一句话：**把它烧进那两块 ESP32，舵机就能替你按电梯的 ▲/▼ 按钮。**

这是硬件那一半的最终版（v8）。软件那一半（安卓 App）在 `安卓App` 包里（v12：井道四层改成 B / 1F / 2F / 3F）。

两块板子的程序**只有 3 行不同**（已逐行比对）：

```
elevator_1F.ino  ↔  elevator_2F.ino
只有这 3 行不一样：
    第 2 行    电梯呼梯节点 —— 1F 板  /  电梯呼梯节点 —— 2F 板
    第 4 行    楼层：1F  /  楼层：2F
    第 58 行   #define FLOOR_NAME  "1F"  /  #define FLOOR_NAME  "2F"
```

（v6 时是第 2 / 4 / 62 行；v7 把头部注释压缩重写、少了两行，`FLOOR_NAME` 因此提前到第 58 行。）

## v8 比 v7 改了什么

1. **按压摆角 40° → 60°**（本次主要改动）：**从“垂直左偏 20°”摆到“垂直右偏 40°”** ——
   松开位 **90° → 70°**（垂直左偏 20°），按下位**仍是 130°**（垂直右偏 40°，v7 手测过的位置）。
2. **行程警告阈值 45° → 65°**（默认才 60°，还是留 5° 余地再提醒）。
3. 顺带按新摆幅算了行程：**销钉沿长槽走 ≈ 7.9 mm**（= 8.0 × (sin40° − sin(−20°))；
   v7 的 40° 是 ≈ 5.1 mm，多走 ≈ 2.7 mm）—— 机械件没换的话，装曲柄、标定时留余量要更上心。
4. 其余**全部没动**：楼层号 1F/2F、BLE 协议、接线（上行 D13 / 下行 D12）、摆臂 350 ms、按住 600 ms；
   `chime_node` 也没有动。

### 存档：v7 比 v6 改了什么

1. 楼层号 2F/3F → 1F/2F：两个程序文件夹、`FLOOR_NAME`、BLE 广播名、串口横幅全部换号；
   **BLE 协议一个字没改**（App 按 `ELEV-` 前缀认设备）。
2. 按压转角 10° → 40°：松开 90° → 按下 130°。
3. 改正 v6 的错误说法：v6 写的“面板沉台 1.6mm、按钮最多压进 1.6mm、按 10° 走 1.39mm”
   是**量错对象、推错结构**得出的，**作废**；真正的硬限位是**长槽两端**，
   行程警告阈值从 11° 放宽到 45°。
4. 摆臂时间保持 350 ms、按住 600 ms。

## 不含什么

- **不含**安卓 App 的源码/安装包 —— 那是 `安卓App` 包（v12 已同步：井道四层 B / 1F / 2F / 3F）。
- **不含** BLE 协议的完整规格 —— 那是 `发给队友` 包里的 `BLE_PROTOCOL.md`。
- **不做**“轿厢在几层”的判断 —— 这两块板子只会**按按钮**，测不出轿厢位置；
  位置来源看 `发给队友_到站检测` 那个包。

## 发货前已经核对过的事

- ✅ 两个 `.ino` 逐行比对：**只有 3 行不同**（第 2 / 4 / 58 行），其余内容一致。
- ✅ `FLOOR_NAME` 各自正确：`elevator_1F` 里是 `"1F"`、`elevator_2F` 里是 `"2F"`（没有搞反）。
- ✅ v8 的两个 `.ino` 用 **arduino-cli 1.5.1 + esp32 core 3.3.12** 重新编译过：
  `PartitionScheme=huge_app`，两块都是 **1,108,134 B（占 35%）**（和 v7 恰好同尺寸 —— 只改了角度数字）。
- ✅ `预编译bin/` 里的两个 `.bin` 就是这次编译的产物（`*.ino.merged.bin` 改名而来），
  **和源码同一版**，不是旧拷贝（各 4,194,304 B）。
- ✅ 包里的源码副本与 `firmware/` 里的源文件**逐字节一致**（SHA-256 对过）。
- ✅ `chime_node` 本版**没有改动**（哈希与 v7 相同）。
- ⚠️ **没有真机验证过**（手上没有硬件）：舵机装齿后的实际绝对角度、
  **舵机转动方向是否与固件假设一致**（不一致就按 `烧录说明.md` 5.3：
  `A10 → SP → SAVE` 一条命令改到另一侧）、按钮与面板的实配间隙，都要现场标定确认。
- ⚠️ 角度是按《MG90S 舵机电梯按钮装置_STL_8件》量的：R ≈ 8.0 mm、长槽 17.5×5.4 mm。
  现场机械件如果不是这套，都要重新量。

## 版本对不上怎么办

本包是 **v8**，取代之前的 **v7**（`烧录程序_v7.zip` 已从磁盘删除，避免两版并存）。

`发给队友_透视井道` 仍 v1、`演示材料` 仍 v2、`项目资料` 仍 v1。
