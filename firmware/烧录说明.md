# 烧录说明 · 电梯呼梯装置（固件 v8）

> 两块板子，程序**只有 3 行不同**（真正要选的只有一行）：`#define FLOOR_NAME`。
> **1F 板**烧 `elevator_1F/elevator_1F.ino`，**2F 板**烧 `elevator_2F/elevator_2F.ino`。
> **两块都烧成同一个就麻烦了** —— 手机会看到两个同名的节点，分不出楼层。

**v8 改了什么（一句话）**：按压摆角 **40° → 60°** —— 从"垂直左偏 20°"摆到"垂直右偏 40°"
（松开 **90° → 70°**、按下**仍是 130°**）；楼层号、接线、BLE 协议**都没动**。
"长槽两端才是硬限位"的结论继续适用（行程 = R×(sinφ₂−sinφ₁)，R ≈ 8.0mm，见第五节）。

## 一、先接线（**烧录之前**先看这段）

| 舵机 | 信号线接到 | 说明 |
|---|---|---|
| **上行 ▲** | **D13**（GPIO13） | 按面板上"上"那个按钮 |
| **下行 ▼** | **D12**（GPIO12） | 按面板上"下"那个按钮 |
| 舵机 VCC（红线） | **外部 5V 正极** | ⚠️ 不要接 ESP32 的 3V3，带不动会抖 |
| 舵机 GND（棕/黑线） | **外部 5V 负极** | ⚠️ 必须和 ESP32 的 GND **接在一起**（共地） |

> ⚠️ **D12 是 ESP32 的特殊脚**（上电瞬间它会影响启动模式）。
> 如果 D12 上挂着舵机信号线，可能出现"烧不进程序"或"上电没反应"。
> **做法：烧录前先把 D12 上那根信号线拔掉，烧完再插回去。**

## 二、用 Arduino IDE 烧（推荐）

1. Arduino IDE 里装好 ESP32 支持包（开发板管理器搜 `esp32` 安装）。
2. 打开对应文件夹里的 `.ino`：
   - 给 **1F** 那块板 → `elevator_1F/elevator_1F.ino`
   - 给 **2F** 那块板 → `elevator_2F/elevator_2F.ino`
3. **开发板**选：`ESP32 Dev Module`。
4. **分区表（Partition Scheme）必须选**：`Huge APP (3MB No OTA/1MB SPIFFS)`
   —— 不选会提示"程序太大"。
5. **串口**：`115200`。选对端口（设备管理器里看是哪个 COM）。
6. 点"上传"。烧完打开**串口监视器**（右下角波特率也选 115200），应该看到：

```
=== 电梯节点启动：ELEV-1F ===  (固件 v8)
[标定] 上电：两轴已停在 REST（松开位）
        上电后确认：销钉在长槽里、离两端都有余量（别顶到槽头）。
[标定] 串口命令（波特率 115200，行尾选"换行"）：
        ?        查看当前角度/设置
        A70      两轴转到绝对角度 70°（找位置用）
        ...
[ble] 广播中，等待 App 连接...
```

> 看到 `ELEV-1F` 就对了。**如果两块板子都打印 `ELEV-1F`，说明烧重了**，把另一块重烧成 `ELEV-2F`。

## 三、不想装 Arduino？直接用预编译固件

`预编译bin/` 里放了两个**已经编译好的完整固件**（和上面的源码是同一版，同一次编译出来的）：

| 文件 | 烧到哪块板 |
|---|---|
| `elevator_1F.merged.bin` | 1F 板 |
| `elevator_2F.merged.bin` | 2F 板 |

用 esptool 一条命令烧，**偏移必须是 `0x0`**：

```
esptool.py --chip esp32 --port COM3 write_flash 0x0 elevator_1F.merged.bin
```

- 把 `COM3` 换成你实际的串口。
- Windows 上命令名叫 `esptool.exe` 也可以。
- 这种方式**连分区表一起写进去了**，所以**不用**再手动选 Huge APP。

## 四、开机自检（1 分钟）

1. 两块板子都上电 → 串口各打印一次启动横幅 + 标定摘要（上面那几行）。
2. **上电瞬间两个舵机都转到"松开位"**（默认 70°＝垂直左偏 20°）：按钮**不被压到**，销钉在长槽里、离两端都留有余量。
   这一步就是第五节标定的起点。
3. 手机装我们的 App（`安卓App` 包 v12），打开 → 应该能扫到 `ELEV-1F` 和 `ELEV-2F` 两个名字。
4. 在 App 里点一下 **▲**，对应那块板子的舵机应该：
   **从垂直左偏 20° 摆到右偏 40°（约 60°）→ 把按钮压动 → 停约 0.6 秒 → 转回来**，然后手机收到 `1F|OK:UP`。
5. 两个方向各试一次（▲ 和 ▼），确认**两个舵机都能动、方向都对**。
   （如果"按下"时按钮反而没被压到（方向反了），看 5.3 最后一段，一条命令就能改过来。）

## 五、舵机角度（v8：60°）+ 现场标定

### 5.1 为什么是 70° → 130°（转 60°）

这套机械件的传动是 **「曲柄 + 长槽滑块」**（苏格兰轭）。它的运动规律就一条：

```
滑块 / 按钮行程 = R × (sinφ₂ − sinφ₁)      φ = 曲柄销钉绕舵机轴的转角
R = 曲柄上"舵机轴心 → 销钉轴心"的距离
```

用程序把那套 STL **一层层切开量**（0.15mm 一刀），量出来：

| 量什么 | 量出来 |
|---|---|
| 舵机齿孔与销钉的圆心距 | **≈ 8.0 mm**（7.98）= R |
| 滑块上的长槽 | 17.5 × 5.4 mm（销钉在槽里滑） |

**关键**：**长槽两端才是硬限位** —— 销钉滑到槽尽头顶住、还让舵机硬转，就是**堵转**：
电流飙升、齿轮"嗡嗡"响，时间长了会烧。**任何时候都要给槽两端留余量。**

**60° 是这一版（v8）定的**：按压终点 130° 是 v7 现场手测过、能可靠压到按钮的位置；起点往左挪 20°（90° → 70°），摆幅因此从 40° 变成 60°。
→ **松开 70°、按下 130°**（默认值）。

按这条公式算新行程：销钉沿长槽走的距离 = 8.0 × (sin40° − sin(−20°)) ≈ **7.9 mm**
（v7 的 40° 只有 ≈ 5.1 mm，这一版多走 ≈ 2.7 mm）—— 装曲柄、标定时给长槽两端留余量要更上心。

> ⚠️ 上一版 v6 这里写的"面板沉台 1.6mm、按钮只能压进 1.6mm、按 10° 走 1.39mm"是**错的** ——
> 量错了对象、推错了结构，v6 的那套结论**已作废**。
> 以本节这条公式 + "长槽两端留余量"为准。

### 5.2 装曲柄时怎么对位

**运行前先上电**（舵机停在"松开位"，默认 70°），再把曲柄装到舵机轴上：

- 销钉**插进长槽里**；
- 松开位时，销钉**离长槽两端都留余量**（不要贴边，目测能看出还有一段）。

⚠️ MG90S 的输出齿是 **25 齿**，也就是曲柄只有 25 个装法，相邻两齿差 **14.4°**。
**靠手感不可能装准**，所以下一步的串口标定是必须做的，
而且**两块板子要分别标**（两个舵机装齿的位置不会一样）。

### 5.3 串口现场标定

打开 Arduino 串口监视器（**115200**，行尾选"换行"），直接打字发命令。
这些命令**只走串口**，App 的 BLE 命令完全不受影响。

| 命令 | 干什么 |
|---|---|
| `?` | 查看当前角度 / REST / PRESS / 存储值 |
| `A125` | 两轴一起转到绝对角度 125°（找位置用） |
| `+1`、`-2` | 在当前角度上微调 |
| `U` / `D` / `B` | 标定对象切到 上行 / 下行 / 两轴（默认两轴） |
| `SR` | 把当前角度记成 **REST（松开位）** |
| `SP` | 把当前角度记成 **PRESS（按下位）** |
| `SAVE` | 存进 Flash（掉电不丢） |
| `T` | 试跑一次：REST → PRESS → 停 0.6 秒 → REST |
| `CLR` | 恢复出厂默认 70 / 130 |

**推荐流程（约 3 分钟，两块板子各做一遍）**：

1. 上电后打 `A70`。看机构：按钮**没被压到**，销钉离长槽两端都留有余量。
2. 不够/过头就用 `+1` / `-1` 微调，到"刚好"为止 → 打 `SR`（记住松开位）。
3. 打 `A130` → 按钮应被压动（按下位）；**再看一眼销钉有没有贴到槽尾**。
4. 打 `SP`（记住按下位）→ 打 `T` 试跑一次，看行程够不够：
   不够就 `A134` → `SP`；顶到槽/憋住就 `A126` → `SP`，再 `T` 看一遍。
5. 满意了打 `SAVE` 存起来（掉电不丢）。

**如果"按下"时按钮反而没被压到**（说明这台舵机/曲柄的装法与我假设的相反）：
把按下位定到松开位的另一侧即可 —— `A10` → `SP` → `SAVE`（松开位 70°，另一侧 = 70° − 60° = 10°）。

**安全提醒**：固件会盯着 `|PRESS − REST|`，超过 **65°** 会打印 ⚠ 警告
（默认才 60°）。看到警告就先手动确认销钉离长槽两端还有余量，再决定要不要收一点。

### 5.4 其它参数（要改代码才生效）

| 参数 | 默认 | 作用 |
|---|---|---|
| `SWEEP_MS` | 350 | 转过去 / 转回来各用多少毫秒（和演示视频 / PPT 的 0.35 秒口径一致） |
| `HOLD_MS` | 600 | 按下去之后**保持**多少毫秒 |
| `UP_PIN` / `DOWN_PIN` | 13 / 12 | 换线的话在这里改 |

> 说明：`ANGLE_REST=70` / `ANGLE_PRESS=130` 只是**出厂默认**。
> 做过 5.3 的标定并 `SAVE` 之后，运行用的是 Flash 里存的值；
> `CLR` 可以一键回到出厂默认。

> ⚠️ **从 v7 升上来注意**：如果你在 v7 上标定过并 `SAVE` 了，板子里 Flash 存的还是**旧角度**，
> 上电会继续用旧值 —— 新默认（70 / 130）**不会自动生效**。要新摆幅就打一次 `CLR`（清回出厂默认），
> 或者按 5.3 重新标定再 `SAVE`。

## 六、附：可选件「到站检测」（不装也能演示）

`chime_node/chime_node.ino` 是一块**另外加装的、完全可选**的板子：
它挂个麦克风听电梯到站的"叮"声，用来判断**轿厢现在在几层**。

- **不装它，整套演示照样能跑**（轿厢位置先用模拟值，界面上会标"模拟"）。
- 要装的话，接线和现场标定步骤看 `发给队友_到站检测` 那个包里的 `CAR_POSITION.md`。
- 它是独立设备（广播名 `CHIME-2F`），**不影响**上面两块呼梯板。
