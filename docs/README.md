# 文档索引

`docs/` 下所有文档的入口。按用途分三类：**协议接口**、**项目说明**、**子目录**。

---

## 阅读顺序建议

1. 先看仓库根目录 [`README.md`](../README.md)，了解整体结构。
2. 想知道**怎么跑起来** → [`android/安装说明.md`](android/安装说明.md)、[`../firmware/烧录说明.md`](../firmware/烧录说明.md)。
3. 想知道**协议怎么对** → [`BLE_PROTOCOL.md`](BLE_PROTOCOL.md)。
4. 想知道**现场怎么讲** → [`演示材料/现场演示手册.md`](演示材料/)。
