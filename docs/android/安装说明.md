## 一、装到手机上

仓库只收源码，先用 Android Studio 打开 `android/`，或命令行构建：

```bash
cd android
./gradlew assembleDebug
```

1. 把 `app/build/outputs/apk/debug/app-debug.apk` 传到手机。
2. 在手机上点开这个 apk → 系统问"是否允许安装未知应用" → 允许。
3. 装好后桌面上叫 **「电梯呼叫」**。
4. 第一次打开会问**蓝牙权限**和**摄像头权限** —— 只要你不点"摄像头读楼层"，
   不给他也能用；要给的话点"允许"就行。

> 这是 **debug 签名**，只能手动安装，不能上应用商店。自用够。

## 二、读电梯在几层（**要用摄像头**）

主界面**左上角**有个小胶囊 **「摄像头读楼层」** → 点进去：

1. 手机会打开后置相机，屏幕中间有个**绿色虚线框**。
2. 把**电梯厅那块红字屏上的数字**框进虚线框里（靠近一点，稳住 1 秒）。
3. 上面的大数字会从 `--` 变成 **`3F`** 这样 —— 读到了；
   如果一次读到两位（甲/乙），旁边会多一个小的 **`乙 1F`**。
4. 点 **返回**，主界面**甲梯**的大数字、井道里的轿厢就都在这一层了
   （v9 起层显框里只有那个大数字，下面不再写小字）。

> 这一页就是"**装在电梯前面的那台监控**"：现在没有固定摄像头，**拿一部手机当它** ——
> 手机对着那块屏、这一页开着，它就一直读，别的页面显示的就是它读到的楼层。

> **v5：读数看得清了，而且屏幕不会自己关。**
> 甲梯那个数是 **72sp 居中大字**，乙梯在旁边 44sp；读到的时候下面那行会变**亮绿**
> 并写 `✓ 已读到 甲 2F`，没读到就是灰的、后面直接写原因。
> **这一页开着的时候屏幕不会自动关** —— 以前会：自动锁屏一触发，相机被放掉、读数就停在那儿，
> 再一看就像是"跟不上真电梯"。
>
> ⚠️ 但**一台手机当监控时，你站在别处是看不到它显示什么的**（摄像头对着厅门屏，屏幕朝厅里）。
> 想"人离得远也能看"，得有**第二块屏**：笔记本打开 `preview/monitor_live.html` 就行。

**右下角那个小方块**是"App 看到的样子"（不是相机画面，是算法真正拿去认数字的图）：
亮的地方是它认出的红点，绿框是它读出数字的位置。现场读不出来的时候，
看这一小块最快知道问题在哪：

| 小方块里的样子 | 说明 | 怎么办 |
|---|---|---|
| 全黑 | 没看到红字 | 对准那块屏、靠近一点 |
| 有亮点、没绿框 | 看到红点了，但没拼成数字 | 再近一点、别抖 |
| 有绿框、数字不对 | 屏上的字形跟标准点阵差太多 | 用下面的**「现场教一下」** |

**「现场教一下」**（页面下方）：**先点 `甲`/`乙` 选是哪台电梯，再点 `B`/`1F`/`2F`/`3F`**
就直接手动指定；摄像头自动读数会**暂停**（不会一秒又被覆盖），旁边出现「恢复自动识别」。

> 没读到的时候不会瞎猜：宁可一直显示 `--`，也不给你一个错的楼层。

## 三、看队友 App 的效果（**不用硬件**）

主界面**右上角**小胶囊 **「队友 App 效果 ▶」** → 进去就是**队友那个导航 App 最后的样子**（我们的模拟版）：

| 页面上有什么 | 说明 |
|---|---|
| **顶部那张卡：电梯现在在 B/1F/2F/3F（大字）** | 你要的"**进去就能看到电梯现在在哪层**"就是这一条 |
| 右边一个**绿色圆钮**（写着 ▲ 1F 呼梯） | 靠近电梯才浮出来。**点一下 = 呼梯** |
| **按住圆钮往左拖** | 进一个**全屏电梯页**（不再是弹出的小面板） |
| 最底下一排**模拟开关** | 手点「你在 / 要去 / 甲梯 / 乙梯」，就能摆出任何状态看效果 |

> **这一页的两台车是有分工的**（演示时我们只模拟一台真电梯）：
> - **甲梯 = 跟着你走**：你在哪层，它就画在哪层（真机上这就是**蓝牙判层**的结果）；
>   点了呼梯，它会**一层一层开过来**，**到了自动开门**、停一会儿再关。
> - **乙梯 = 纯装饰**：B~3F **随机慢慢跑**（每 3 秒多换一次，一次跳 1~2 层）。
>   它**不代表任何真实读数**，井道上挂着 `乙梯` 小胶囊、页面上方那行也写着"乙梯随便跑"
>   （v9 起层显框里只有大数字，下面**不再写** `模拟 · 另一台电梯` 那种小字）。
> - 所以你**怎么点都不会"两台一起动"** —— 只有甲梯跟你有关系。

### 向左拖出来的**全屏电梯页**长什么样

```
 ← 地图        电梯呼叫
      甲梯跟着你走，乙梯随便跑 · 有真读数就是真实值

      ┌────────┐   ┌────────┐
      │   1F   │   │   2F   │      ← 甲梯 / 乙梯（两个层显**一样大**）
      └────────┘   └────────┘

      ┌──────┐     ┌──────┐
      │ 甲梯 │     │ 乙梯 │     ← 两台井道并排；甲跟你在 1F，乙自己跑
      │  ┌──┐│     │      │
      │  │轿││     │ ┌──┐ │
      │  └──┘│     │ │轿│ │
      │ B~3F │     │ └──┘ │
      └──────┘     └──────┘

          B   1F  2F  3F        ← 要按哪一层的装置（B / 3F 灰掉）

            ▲          ▼        ← 点一下 = 呼梯（模拟）

         ● 靠近 1F · 去 3F → 按 1F 的上行 · 在线 2/2（模拟）
```

- 点 **`← 地图`**（或按手机返回键）就回地图。
- **甲梯跟着你**：你说你在 1F 它就在 1F；点一下绿钮呼梯 → **它一层层开到 1F → 到站开门 → 门关上**。
- **乙梯自己随便跑**（最底下那排「乙梯」后面的 **「自动」** 亮着）；想让乙梯停下来，点一下「自动」，
  之后可以手点乙梯的 B~3F 把它摆到某一层。
- 默认：**你在 1F、要去 3F**，绿钮显示 **▲ 1F**。
- 点一下绿钮 → `正在呼叫…` → 约 1.3 秒后 `✓ 收到 1F|OK:UP` → **轿厢一层一层开到 1F**。
- 大屏里的 ▲/▼ 也一样能呼梯（跟着上面选的"要按哪一层"）。

### 呼梯就只有两种点法（v10 起）

| 怎么呼 | 说明 |
|---|---|
| 绿钮（`▲ 1F 呼梯`） | 按"你所在的层 + 目的地算出的方向"呼一次（真机上就是向那块 ESP32 写 `UP`/`DOWN`） |
| 大屏里的 **▲ / ▼** | 按上面选的"要按哪一层的装置"呼一次 |
| （真机上）队友导航 App 的悬浮钮 | 走蓝牙，和上面两种完全一样 |

- 成功以**装置回执**为准：约 1.3 秒后底部出现 `✓ 收到 1F|OK:UP`。
- **v10 起 App 里没有语音了**（你说手机上识别不了）：🎤 语音呼叫按钮、`VoiceController.kt` `VoiceParse.kt`
  两个文件、**麦克风权限**都删掉了 —— 装 v10 之后**不会再问麦克风权限**。
- 呼梯入口**永远只有"人主动点"这一种**：没有任何定时器、没有"靠近就自动呼"。

> ⚠️ 这一页里凡是标了 **"模拟"** 的数字都是**摆出来给你看的**（它故意不接真数据，
> 好让你随时摆出任何状态）。真机上：轿厢楼层来自**摄像头读电梯屏**（这条路**现已搁置**，
> 现在默认用**蓝牙判层**），呼梯来自**蓝牙写 UP/DOWN**。
> 如果摄像头那一页刚好读到过（3 分钟内），这里会直接显示**真实值**并标 **`真 · 摄像头 · 刚刚`**。

## 四、两台电梯（v3 新增）

一栋楼并排两台电梯是常态，电梯厅那块横屏**左边一位 = 甲梯、右边一位 = 乙梯**。

- 摄像头那一页**一次就把两位都读出来**（按列空隙切开，左边那位给甲、右边那位给乙），
  所以**一台摄像头就能同时盯两台**。
- 只读到一位（只有一台电梯 / 另一台没框进来）也照样用，另一位就留空。
- 我们的呼梯装置只装在**其中一台**（就是甲梯，1F/2F）；乙梯只是"看着它的位置"。
- 给队友的接口里：`car` = 甲梯、`carSource` = 来源、`car2` = 乙梯。

## 五、主界面（老界面）长什么样 —— v9 起也是**两台电梯**

```
              电梯呼叫
   甲梯跟着你走 · 乙梯是另一台（模拟）· 点 1F/2F + ▲▼ 呼梯

        ┌────────┐   ┌────────┐
        │   1F   │   │   2F   │   ← 甲梯 / 乙梯 两个层显，一样大、各占一半
        └────────┘   └────────┘      框里**只有数字**，下面没有小字

        ┌────────┐  ┌────────┐
        │  甲梯  │  │  乙梯  │   ← 两台井道并排（甲跟着你，乙自己跑）
        │   ┌──┐ │  │   ┌──┐ │
        │   │轿│ │  │   │轿│ │
        │   └──┘ │  │   └──┘ │
        └────────┘  └────────┘

            B   1F  2F  3F      ← 要按哪一层的装置（B / 3F 灰掉）

              ▲          ▼      ← 点一下 = 呼梯
         外部接口 http://…:8899 · 找到 1 台装置 · 等靠近 1F / 2F
```

- **甲梯** = 会跟着你走的、也是**唯一真能呼**的那台（见下面那个来路说明）；
- **乙梯** = **另一台电梯**，B~3F **随机慢慢跑**，纯画面装饰（和大屏里那台一模一样）；
- **层显框里只有一个大数字**（v9 改的）：数字下面**不再有小字**；
  "装置找到没找到 / 正在检测 / 呼叫目标"这些都写在**页面最下面那条状态栏**里。

**甲梯层显上那个大数字 = 轿厢现在在哪层**，来路按优先级：

```
① 真实读数（摄像头读到的 / 现场手动指定的）
        ↓ 没有的话
② 蓝牙判层：你靠近哪一层的 ESP32，轿厢就画在那一层
   （你拿着手机坐在轿厢里时，这就是轿厢所在层；只判得出来装了装置的 1F / 2F）
```

数字的来路（真读数 / 蓝牙判层）现在写在这两处，**不再写在层显下面**：

- 「队友 App 效果」页顶部那张卡（`真 · 摄像头 · 刚刚` / `蓝牙判层`）
- 给别的 App 的接口（`/api/status` 里的 `carSource`）

> 读数超过 **3 分钟**没人再看它，就自动退回**蓝牙判层** —— 免得一个过期的数字冒充"实时"。
> 两条来路都是**有依据的**（真读数 or 你人在哪层），不是编出来的数；编出来的那个只有**乙梯**
> （纯装饰、随机跑、不进接口）。

  全屏电梯页按 360×780 算过（网页版逐块量过：不越界、不重叠），
  **v9 的主界面**：两个层显改成**各占屏幕一半宽**（永远一样大、任何屏宽都不会被挤掉），
  下面两台井道并排、自动占剩下高度；但**真机上的观感**（够不够高、挤不挤）只有你装了才知道。
- **v8 的开门效果**：逻辑和网页版是同一套（网页版上**逐像素量过**：关门时门缝 2px；
  开门后门缝里从上到下、从左到右各能数出 6 种颜色 = 地板/侧壁/后壁/顶灯，**不是一块同色的黄**）。
  但**手机上看着好不好看**只有你装了才知道；想改亮一点/暗一点、灯大一点小一点，说一声。
- **v7 的乙梯随机跑**：现在是**每 3 秒多**换一层、一次跳 1~2 层。嫌快/嫌慢说一声（改一个数的事）。
- **没在真机上开过摄像头**：预览方向对不对、能认到多远的距离，都要你现场试。
  万一预览是**躺倒的**、或者**一直读不出来** —— 截个图告诉我，我马上调。
- 识别算法本身是拿**真机照片**离线验过的（两张照片都读出 `'1'`，
  蓝色轿厢屏读出 0 个数字，降一半分辨率也一样），但**只见过数字 `1`**。
- **"两台电梯"是按"厅里那块屏左右两位"理解的**：左边 = 甲、右边 = 乙。
  如果现场其实是"两台电梯各有一块屏、隔得比较远"，那要看一台摄像头能不能把两块屏都框进去；
  框不进去就只显示一台（算法会自动只更新它看到的那一位）。
- 所以：**如果你装了之后发现哪个字挤了、哪块挡了、哪个按钮点不到、摄像头躺倒了 ——
  告诉我一句，我马上调。**
