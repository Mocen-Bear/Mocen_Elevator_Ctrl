## 3. 现场运行方案

> 详细的、给自己人看的操作手册在 `演示材料/现场演示手册.md`。这里只列提交需要的骨架。

### 3.1 硬件清单（一个双肩包）

| 物品 | 数量 | 说明 |
|---|---|---|
| ESP32 开发板 | 2 | 已烧 `elevator_2F.ino` / `elevator_3F.ino`（预编译 bin 在 `烧录程序/预编译bin/`） |
| MG90S 舵机 | 2 | 装在面板上；**VCC 必须接外部 5V，严禁接 3V3** |
| 外部 5V 电源 | 1 | 充电宝 + 5V 升压模块；**GND 必须与 ESP32 共地** |
| 安卓手机 | 2 | 装 `安卓App/电梯呼叫_v10.apk`（第二台作为备份） |
| 固定件 | 若干 | 美纹纸胶带 / 扎带 / 泡棉胶 —— 用来把舵机臂对准呼梯按钮 |
| 笔记本 | 1 | 开 `preview/` 里的网页演示台（离线可用） |
| 3D 打印样机（可选） | 1 套 | 打印件 + 装配说明书；能带来就在展台演示"按钮真的被按下去" |
| 接线与工具 | 1 套 | 杜邦线、备用 Micro-USB 线、小螺丝刀 |

### 3.2 场地要求

- **任意一部 ≥ 4 层的电梯**，我们只在 **2F 和 3F 的电梯厅**贴装置（这两层才有板子）。
- 贴装置的位置：呼梯按钮旁边，用胶带固定；**不挡人、不挡按钮、10 秒可拆**。
- 需要一点点手机信号/蓝牙环境 —— 我们**不需要 Wi-Fi、不需要互联网**。

### 3.3 到场后 10 分钟落地（四步）

1. **贴装置**：舵机臂对准呼梯按钮，手动试一次行程（松 → 按到底），确认按钮真的被压下。
2. **通电**：看板载 LED / 串口启动正常，手机蓝牙能看到 `ELEV-2F`、`ELEV-3F` 两个名字。
3. **点一次 UP**：确认三件事同时发生 —— 舵机动、呼梯灯亮、手机收到 `2F|OK:UP`。
4. **记一次信号**：站在 2F 门口和 3F 门口各看一次 App 上的 dBm，**两者差 ≥ 8 dB** 才稳；
   差得少就把装置往门口再贴一点。

### 3.4 3 分钟演示脚本

| 时间 | 动作 | 台词 |
|---|---|---|
| 0:00 | 站在 2F 电梯厅，掏出手机 | "我们现在在电梯厅。**我们不碰任何公共按钮。**" |
| 0:15 | App 上"2F 上行"按钮自动浮现 | "手机靠蓝牙信号强度就知道我在 2F、离井道多近 —— **按钮自己浮出来**。" |
| 0:25 | 点一下按钮 | "点一下就行。" |
| 0:30 | 指墙上：舵机动、灯亮 | "**看，舵机真的把电梯的按钮按下去了**，呼梯灯亮。" |
| 0:40 | 手机收到回执 | "回执 `2F\|OK:UP` —— 这表示**我的动作完成了**。" |
| 0:50 | 打开井道透视 | "抬头看：**井道就是叠在走廊上的**。" |
| 1:00 | 轿厢动画下来 → 到站 | "轿厢从 4F 下来，到 2F。"（**如果是模拟，主动说"这里的位置是模拟的"**） |
| 1:20 | 再点一次 ▲/▼ 呼一次 | "呼梯永远是「**你所在那一层**」的按钮；去哪层只用来决定上/下。" |
| 1:40 | 收尾 | "**呼梯是真的；位置我们没装传感器前不假装。**" |

> **主动说"模拟"是加分，不是减分。** 一句话就补上：
> "位置我们现在是模拟的，但两条真实位置的路已经写好代码了 —— 一个听电梯到站的叮声，一个用摄像头读电梯自己的楼层显示（实测单帧 84~89% 读对）。"

### 3.5 出问题怎么办（照表走，别现场发呆）

| 症状 | 先查 | 还不行 |
|---|---|---|
| 舵机不动 | 舵机 5V 有没有？GND 共地没有？D12 烧录时拔了有没有插回？ | 手动按一下按钮，只演示"手机浮出按钮 + 井道透视" |
| 手机扫不到 `ELEV-*` | 板子还在广播吗（串口打印）？关开一次手机蓝牙；重启板子 | 换第二台手机；或用笔记本 Chrome 开 `preview/ble_console.html` 直接点 UP/DOWN |
| 楼层数字乱跳 | 站远/站近 30 cm 再看 | 用 `preview/rssi_floor_sim.html` 现场选参数（滞后提到 4~5 dB、连赢 2 次） |
| 电梯半天不来 | 别干等 | 改演"按下 → 灯亮 → 回执"，轿厢说"用模拟演示行进" |
| App 崩了 / 手机没电 | — | 开 `preview/elevator_3d_preview.html` 或 `elevator_ui_preview.html` 顶上 |
| **什么都跑不起来** | — | ⭐ 开 `preview/storyboard.html` 点「放映模式」（或按 `F`）：30 秒把全流程演完，**不用任何硬件** |

### 3.6 演示前 60 秒"最后一分钟"检查

```
[ ] 板子通电、串口有打印、手机看得到 ELEV-2F 和 ELEV-3F
[ ] 点一次 UP：舵机真的动、灯真的亮（这一步一定要在下楼之前做！）
[ ] 手机亮度拉满（呼梯按钮要看得到）
[ ] preview/storyboard.html 已经在浏览器里开着（保险）
[ ] preview/elevator_3d_preview.html 已经开着（别现场找文件）
[ ] 提交的演示视频_备用.mp4 已经拷到桌面（终极保险）
```

## 5. 彩排建议

1. **完整走一遍 3 分钟脚本**（含"如果电梯不来"的分支），至少两遍。
2. **故意拔掉舵机电源**再走一遍 —— 练的就是"舵机不动"这条退路。
3. **提前把第 6 页（能力边界）背熟**，尤其是被追问"你怎么知道电梯在几楼"的标准答法。
4. **提前把第 8 页的三个数字背熟**：25.7 次 → 4.3 次 → 1.3 次；真机判定 40~200 ms。
