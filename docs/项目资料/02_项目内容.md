## 一、代码仓库链接

> ### ⚠️ 提交前请做一件事（大约 3 分钟）
> 我们**已经把仓库做成了可以直接推送的状态**（本地已有完整的 git 历史、已验证可用），
> 但**把仓库推到公网需要一个账号，这件事只能由队伍自己做**。做完把链接填进下面这张表：
>
> | 项目 | 内容 |
> |---|---|
> | 公开仓库链接 | **【待填：把下面的仓库推上去后，把 URL 粘到这里】** |
> | 代码托管平台 | GitHub / Gitee / 校内 GitLab（任选） |
> | 默认分支 | `master` |
> | 提交历史 | **多次提交**（`git log` 可查） |
> | 仓库文件数 / 体积 | 128 个文件 / 约 11 MB（纯源码与文档；**不含** APK 与压缩包） |

### 1.1 三种"把仓库推上去"的办法（选一种，都能在 3 分钟内完成）

**办法 A：用 GitHub Desktop / VS Code（最省事）**
1. 打开 `项目资料\代码仓库\elevator-control\` 这个文件夹 —— **它本身就是一个完整的 git 仓库**（含 `.git`）。
2. 用 GitHub Desktop「Add existing repository」选中它 → Publish（或 VS Code 打开后点"发布分支"）。
3. 得到形如 `https://github.com/<你的账号>/elevator-control` 的链接 → 填进上表。

**办法 B：本机装了 git 的话（命令行）**
```bash
cd "项目资料\代码仓库\elevator-control"
git remote add origin https://github.com/<你的账号>/elevator-control.git
git push -u origin master
```

**办法 C：本机没装 git（这台机器就是这种情况）—— 用我们打的 bundle**
`项目资料\代码仓库\elevator-control.bundle` 是一个**标准的 git 打包文件**（已在本机验证可还原）：
```bash
git clone elevator-control.bundle elevator-control
cd elevator-control
git remote set-url origin https://github.com/<你的账号>/elevator-control.git
git push -u origin master
```

> 依据：本机**没有安装 git 命令行**（也没有 GitHub/Gitee 的账号凭据），
> 所以"推送到公网"这一步我们无法代做 —— 但仓库本身、历史、打包文件都已经做好并验证过了。
> 为了方便对方**在没有网络 / 仓库打不开时也能看到全部源码**，我们另外做了一个
> **单文件离线代码浏览器**：`项目资料\代码浏览_离线版.html`（双击即可，约 1.2 MB，1.17 MB 源码全嵌在里面）。

### 1.2 仓库里有什么（对方从哪里看起）

```
elevator-control/
├── README.md               ← 项目总说明：物料、接线、烧录、App 使用、演示脚本、BLE 协议、对外接口

├── android/                ← Android App（Kotlin）完整工程，Android Studio 可直接打开

│   ├── elevator_2F/        ← 2F 板固件（D13 上行 / D12 下行）

├── API.md                  ← 对外 HTTP 接口规格
├── SHAFT_MODEL.md          ← 3D 井道几何规格（安卓 / 网页 / AR 三端同一套数学）
├── NAV_APP_UI_SPEC.md      ← 悬浮呼梯按钮交互规格
├── CAR_POSITION.md         ← "轿厢真实在哪层"的两种做法

```

### 1.3 怎么把代码跑起来（审阅复现）

| 想做什么 | 怎么做 | 需要什么 |
|---|---|---|
| **最快：看演示** | 双击 `preview/index.html`（或用任意静态服务器打开） | **什么都不用装**，纯本地文件 |
| 看控制链 3D | 双击 `preview/elevator_3d_model.html` | 同上 |
| 编译 App | Android Studio 打开 `android/`，或 `gradlew assembleDebug` | JDK 17 + Android SDK |
| 烧固件 | Arduino IDE 打开 `firmware/elevator_2F/elevator_2F.ino` | Arduino IDE + ESP32 支持包（core 2.x/3.x 都行） |
| 重新生成机械模型 | `python 机械件_演示样机/cad/build.py` | numpy / manifold3d / trimesh / Pillow（4 个开源库，见第五部分） |

> **注意**：仓库里**不含 APK 与固件压缩包**（那是构建产物）。要直接安装的手机包，见
> `安卓App/电梯呼叫_v10.apk`（随 `安卓App_v10.zip` 分发）。这样做的目的是让仓库保持"纯源码"。

## 二、私有仓库 → 给对方开通访问（三选一）

如果我们最终把仓库设为**私有**，请**任选一种**方式保证对方能访问，并把结果写在提交表单里：

| 方式 | 怎么做 | 备注 |
|---|---|---|
| **① 直接设为公开（推荐）** | 仓库 Settings → 最下面 Danger Zone → Change visibility → Public | 最简单、最不容易出错 |
| **② 把对方加成只读成员** | Settings → Collaborators → Add people → 填组织方给的账号 / 邮箱 → 权限选 **Read** | 适合不想完全公开 |
| **③ 生成只读令牌** | GitHub: Settings → Developer settings → Fine-grained token，只勾 **Contents: Read**，有效期设到项目结束；Gitee: 私人令牌 | 把令牌**单独**发给组织方，不要写在公开材料里 |

> 无论用哪种，请在提交表单的"代码仓库链接"一栏把**最终可访问的 URL**填上，
> 并注明"公开 / 已授权 / 令牌已发送"。

## 四、第三方工具 / 开源库 / API / 模型 / 数据集 —— 说明

> 完整逐条清单（含版本号与许可证）在 **`01_说明文档.md` 第五部分**。这里给的是"速查版"。

### 4.1 产品本身用到的第三方（都是系统自带能力 / 公开开源）

| 层 | 用了什么 | 许可证 | 说明 |
|---|---|---|---|
| Android App | **AndroidX**（core-ktx / appcompat / constraintlayout / recyclerview）+ **Google Material Components** | Apache-2.0 | 基础控件与 Material 组件；**没有**任何第三方网络库、图片库、框架 |
| Android App | Kotlin 标准库、Android SDK 的 **BLE / Camera / HttpServer** 能力 | Apache-2.0 / Android SDK | 蓝牙、相机、对外 HTTP 接口**全部用系统 API 自己实现** |
| ESP32 固件 | **ESP32 Arduino Core**（`BLEDevice`/`BLEServer`/`BLEUtils`/`BLE2902`）+ **FreeRTOS** | LGPL-2.1 / MIT | 芯片厂商官方核心；**刻意不用第三方舵机库**，直接用核心自带 LEDC 出 50Hz（core 2.x/3.x 都能编译） |
| 网页 | 浏览器自带的 **Canvas 2D** / **Web Bluetooth**（W3C 标准） | — | 全部页面**手写 HTML/CSS/JS，零框架、零 CDN** |

### 4.2 做模型 / 做材料时用的工具链（**不是产品的一部分**）

| 名称 | 用途 | 许可证 |
|---|---|---|
| Python 3.12 · NumPy · Pillow | 参数化建模、自写 z-buffer 渲染器、出图 | PSF-2.0 / BSD-3 / HPND |
| **manifold3d**（CAD 内核）· **trimesh**（网格） | 实体布尔运算、STL 读写与校验 | Apache-2.0 / MIT |
| **python-pptx** | 生成提交用 `.pptx` | MIT |
| **OpenCV** · **imageio + imageio-ffmpeg** | 生成演示视频（逐帧写 MP4 + 编码） | Apache-2.0 / BSD-2 / LGPL |
| **dulwich** | 本机没有 git，用纯 Python 生成 git 仓库与 bundle | Apache-2.0 / GPL-2.0 |
| Node.js | 本地静态预览服务器 | MIT |
| Windows 系统字体（微软雅黑等） | **仅**在渲染图片时调用，**未随包分发字体文件** | 系统自带 |

> 说明：这台机器上没有 OpenSCAD、没有 Blender、没有 git 命令行 —— 所以机械模型的
> 实体建模 / 渲染 / 校验、以及 git 仓库的生成，都是**用自己的脚本 + 上述开源库**完成的。

### 4.3 API / 云服务 / 大模型 / 数据集

| 类别 | 结论 |
|---|---|
| 第三方 Web API、云服务、付费 SDK | **无**（App 走 BLE + 本机 HTTP，**离线可用**；现场断网也能演） |
| 第三方 AI 大模型（作为产品功能） | **无**。App 曾在 v7 做过语音呼梯，**v10 已把语音整条删除**（真机上手机自带识别对"去三楼/上行"这类短句不稳），按钮、代码文件、麦克风权限一并删掉 |
| 第三方模型权重 / 预训练模型 | **无** |
| 公开数据集 | **无**。楼层判定用的是**我们自建的室内 BLE 传播仿真模型**（代码就在 `preview/rssi_floor_sim.html`，可现场跑） |
| 训练 / 微调 | **无**（全项目没有任何模型训练环节） |

### 4.4 一段可以直接粘进提交表单的话

> 本项目使用的第三方组件仅为 AndroidX / Google Material / ESP32 Arduino Core / FreeRTOS
> 等公开开源软件（均按其许可证标注，完整清单见《说明文档》第五部分）。
> 项目**未使用任何第三方 AI 模型权重、未使用任何公开数据集、未接入任何付费 API 或云服务**；
> 全部功能（蓝牙判层、呼梯、3D 井道、机械结构、文档与演示材料）均为本队原创。
