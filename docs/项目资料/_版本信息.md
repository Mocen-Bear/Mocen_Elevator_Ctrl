## 这一版怎么来的（都是本机算出来的，可复核）

| 产物 | 用什么做的 | 生成脚本/来源 |

| 9 张 CAD 图 + 8 个 STL | 本机 Python + numpy 自写光栅渲染器（**没用 OpenSCAD / Blender**） | `机械件_演示样机/cad/build.py`、`render.py` |

| 离线代码浏览器 | 本机 Python，把仓库文本内嵌进单文件 HTML | 128 个文件 / 1.17 MB 文本 |
| git 仓库 + bundle | 本机纯 Python 的 `dulwich`（**本机没有 git 命令**） | 128 文件；bundle 已回灌验证 |
