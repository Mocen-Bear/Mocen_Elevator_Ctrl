## 这些材料怎么来的（本机产物，可复核）

| 产物 | 做法 | 来源 |
|---|---|---|
| 9 张 CAD 图 + 8 个 STL | 本机 Python + numpy 自写光栅渲染器（未使用 OpenSCAD / Blender） | `mech/cad/build.py`、`render.py` |
| 尺寸 / 间隙 / 干涉数据 | 同一份 `build.py`（20 个位姿逐对检查） | `mech/参数与校验报告.md` |
| 演示视频 | 本机 `cv2` + `imageio/libx264` 逐帧合成 | 临时脚本 `make_video.py`（不在仓库内） |
| PPT | 本机 `python-pptx` | 插图即上面的 CAD 图 |
