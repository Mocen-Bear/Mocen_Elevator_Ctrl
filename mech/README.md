# 增压结构件（`mech/`）

自制呼梯装置的机械部分：用 Python 脚本**参数化建模**，导出 STL 直接 3D 打印，再渲染出图。

## 目录

| 路径 | 内容 |
|---|---|
| [`说明书_装配与使用.md`](说明书_装配与使用.md) | **先看这个**：装配顺序、打印参数、现场调试 |
| [`参数与校验报告.md`](参数与校验报告.md) | 关键尺寸、行程、按压量的校验结果 |
| `cad/build.py` | 参数化建模脚本，改参数即可重新生成全部零件 |
| `cad/render.py` | 渲染脚本，输出 `renders/` 下的图 |
| `cad/_run.txt` | 运行记录（环境、耗时、输出） |
| `stl/` | 8 个零件，可直接切片打印 |
| `renders/` | 9 张渲染图：总装、剖视、爆炸图、零件一览、打印摆放、原理图 |

## 重新生成

```bash
cd mech/cad
python build.py      # 重新导出 stl/
python render.py     # 重新渲染 renders/
```

改尺寸只改 `build.py` 顶部的参数区，不要直接改 STL——STL 是产物，覆盖率会丢。

## 装配要点

- 按钮分**上 / 下**两件，方向装反会导致行程不足，按压不到位。
- 曲柄与滑块的配合面是受力点，打印后需要打磨去掉毛刺。
- 具体间隙与螺栓规格见 [`说明书_装配与使用.md`](说明书_装配与使用.md)。
