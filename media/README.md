# 媒体素材（`media/`）

演示用的视频与图片素材。与 `docs/media/` 的分工：

| 目录 | 存什么 |
|---|---|
| `media/`（本目录） | **可播放 / 可剪辑**的原始素材，如演示视频 |
| `docs/media/` | **文档配图**，按文档归档（接线、界面、3D 预览…） |

## 现有素材

| 文件 | 大小 | 用途 |
|---|---|---|
| [`demo/演示视频_备用.mp4`](demo/演示视频_备用.mp4) | 5.08 MB | 现场演示的备用录像，设备故障时可直接播放 |

## 使用约定

- 演示视频是**兜底**，不是主手段：现场优先走真实链接，出问题再播。
- 分镜与旁白节奏见 [`../docs/项目资料/演示视频_分镜脚本.md`](../docs/项目资料/演示视频_分镜脚本.md)。
- 大文件请走 `releases/` 或直接放网盘，不要往 `media/` 里堆——仓库会变重。
