# 交接包（`packages/`）

按**接收方**拆好的三份独立交接包。每份都能单独打包发出去，不用甩整个仓库。

| 包 | 给谁 | 核心内容 |
|---|---|---|
| [`发给队友/`](发给队友/) | 做导航 App 的同学 | BLE 协议、App 接口、iOS 接入、界面规格、交接说明 |
| [`发给队友_到站检测/`](发给队友_到站检测/) | 负责「轿厢在哪层」的人 | `CAR_POSITION.md`：轿厢位置来源与上报约定 |
| [`发给队友_透视井道/`](发给队友_透视井道/) | 负责 3D 井道的人 | `SHAFT_MODEL.md`：模型规格、坐标系、材质与验收清单 |

## 包内文件

### `发给队友/`

| 文件 | 内容 |
|---|---|
| `BLE_PROTOCOL.md` | BLE 广播、服务/特征、命令与回执 |
| `API.md` | App 对外最小 HTTP 接口 |
| `IOS_INTEGRATION.md` | iOS（CoreBluetooth）接入步骤 |
| `NAV_APP_UI_SPEC.md` | 悬浮呼梯按钮的交互规格 |
| `HANDOVER.md` | 交接说明与验收点 |
| `monitor_live.html` | 联调用的实时监视页 |
| `_版本信息.md` | 包版本与变更 |

### `发给队友_到站检测/`

| 文件 | 内容 |
|---|---|
| `CAR_POSITION.md` | 轿厢位置的三条来源与上报格式 |
| `_版本信息.md` | 包版本与变更 |

### `发给队友_透视井道/`

| 文件 | 内容 |
|---|---|
| `SHAFT_MODEL.md` | 井道尺寸、坐标、材质、验收清单 |
| `_版本信息.md` | 包版本与变更 |

## 约定

- 每个包自带 `_版本信息.md`，发包时**连版本信息一起发**，对方才知道对的是哪一版。
- 包内文档可能与 `../docs/` 下的同名文档不完全同步；发生冲突时，**以 `../docs/` 为准**，并以本包版本信息记录的日期判断新旧。
- 只想让对方看协议，就不要把 `../mech/`、`../android/` 的源码一起发过去。
